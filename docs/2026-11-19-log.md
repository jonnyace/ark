## Field Manual Vault added to the local library (not published)
- Source: `~/books/T.Rex Arms Field Manual Vault ZIM/field-manual-vault_eng_2026-11.zim`. It is a 21.8 GB Kiwix ZIM from T.REX ARMS, built 2026-11-17. It holds 6,472 US military publications as pandoc-reflowed EPUB chapters plus 411k webp figures. Each one links to its original PDF on trex-arms.com.
- Format choice: one HTML file per publication.
  - Why HTML: the reflowed text is already on disk, is small, and gets section-level search and citations.
  - Not PDFs: those would mean 6,472 downloads, and text extracted from scanned pages is worse.
  - Not articles: they render the same as HTML, and these are documents.
- Converter: `fmv2ark.py`, kept next to the ZIM. It needs `pip install libzim` in a venv. libzim is GPL, so the converter is not part of Ark.
  - Chapters are joined into one file because Ark's viewer follows only `#` links. `chNNN.xhtml#x` links are rewritten to `#x`.
  - `<section id>` ids move onto h2/h3, so `html_text` indexes sections.
  - Images go into a shared `img/` folder and are listed per resource in `assets`.
- Packs: 19 `local.fmv.*` documents packs. The Doctrine family is split by subcategory, because one pack would have exceeded the 32 MB manifest limit (184k files and 110k sections). Each of the other five families is one pack.
  - They are unsigned, `redistributable: false` and `LicenseRef-US-Government-Works`. Some items, such as NATO AASTP, carry their own release conditions, so they must not go into the public catalog.
  - All are installed in `~/.local/share/ark-library` (about 26 GB) and pass verify. Cross-pack search works.
  - Sources are in `.../ark-src` and built packs in `.../ark-out`, about 23 GB each. Both can be deleted, since the library keeps its own copy.
